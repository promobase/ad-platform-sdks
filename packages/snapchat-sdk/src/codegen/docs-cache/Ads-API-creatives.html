Creatives

A Creative is the combination of one or more pieces of media. Creative is owned by an Ad Account and can be used by multiple Ads simultaneously.

See dedicated sections for examples on how to set up and launch Lens Creatives.

Chat Properties​

A Creative that contains the chat_properties attribute can have it's behaviour tailored for the chat tab where a user may open the Creative and interact with the Creative by sending it a message.

The required conditions to use the chat_properties are the following:

  • Creative type is WEB_VIEW, APP_INSTALL, COMPOSITE
  • A Public Profile ID needs to be attached to the Creative via profile_properties
  • When chat_properties is added to a COMPOSITE (Story) creative, none of the Creatives listed in the composite_properties under creative_ids are allowed to have chat_properties declared on them.

Visuals of Branded Chat Background (wallpaper_media_id), chat message (additional_messages) and auto responses(default_responses) can be viewed in the Help Centre article for Ads in Chat.

chat_properties

Create a Partnership Ad Creative​

If a Creator has accepted an invite request from an advertiser for a collaboration, the advertiser will be able to set up partnership creatives which use the attribute creator_partnership_type, these types of creatives come in two different types:

Brand Partnership​

This type of creative uses 'creator_partnership_type':'BRAND_PARTNERSHIP' and uses an organic snap posted by the creator as a top snap. The creator tags the advertiser in an organic posted Snap, the advertiser will be able to find and claim the snap in order to link the Media entity to their own Ad Account.

The advertiser should use this Media entity as a top snap in a Partnership creative, this creative will use the advertisers own public profile and should define this by setting 'primary_profile':'BRAND'

The metrics when this Creative runs as an Ad will be a combination of the organic metrics and the paid metrics from the advertisers ad.

Ad Partnership​

This type of creative uses 'creator_partnership_type':'AD_PARTNERSHIP' and a media file provided by the advertiser, but using the Creator's public profile, to make such a selection the first step would be to list all creators that the advertiser has a collaboration set up with.

The advertiser should select the creator in question and then go ahead and set up a Creative setting primary_profile: "CREATOR"

The following example creates a new Creative and immediately associates it with an existing Offer Disclaimer.

curl -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer meowmeowmeow" \
  'https://adsapi.snapchat.com/v1/adaccounts/82225ba6-7559-4000-9663-bace8adff5f2/creatives' \
  -d '{
        "creatives": [{
            "name": "Creative With Initial Disclaimer",
            "ad_account_id": "82225ba6-7559-4000-9663-bace8adff5f2",
            "type": "SNAP_AD",
            "top_snap_media_id": "7a317143-b919-4cb0-a2c4-37e80cae0c1b",
            "offer_disclaimer_id": "3d7f2c99-1a2b-3c4d-5e6f-7890abcdef12"
            }]
       }'

Updating a Creative's Offer Disclaimer​

You can add, change, or remove a disclaimer association from an existing Creative by making a PUT request with the full, updated Creative object.

PUT /v1/adaccounts/{ad_account_id}/creatives/{creative_id}

Example: Adding a Disclaimer to an Existing Creative​

Include the offer_disclaimer_id in the payload for a Creative that doesn't have one.

curl -X PUT \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer meowmeowmeow" \
  'https://adsapi.snapchat.com/v1/adaccounts/82225ba6-7559-4000-9663-bace8adff5f2/creatives' \
  -d '{
        "creatives": [{
            "id": "7d4ce4d3-db51-4b9c-8841-0992fc589484",
            "name": "Creative With Added Disclaimer",
            "ad_account_id": "82225ba6-7559-4000-9663-bace8adff5f2",
            "type": "SNAP_AD",
            "top_snap_media_id": "7a317143-b919-4cb0-a2c4-37e80cae0c1b",
            "offer_disclaimer_id": "3d7f2c99-1a2b-3c4d-5e6f-7890abcdef12"
            }]
      }'

Example: Changing a Disclaimer on an Existing Creative​

Update the offer_disclaimer_id to a new, valid disclaimer ID.

curl -X PUT \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer meowmeowmeow" \
  'https://adsapi.snapchat.com/v1/adaccounts/82225ba6-7559-4000-9663-bace8adff5f2/creatives' \
  -d '{
        "creatives": [{
            "id": "7d4ce4d3-db51-4b9c-8841-0992fc589484",
            "name": "Creative With Changed Disclaimer",
            "ad_account_id": "82225ba6-7559-4000-9663-bace8adff5f2",
            "type": "SNAP_AD",
            "top_snap_media_id": "7a317143-b919-4cb0-a2c4-37e80cae0c1b",
            "offer_disclaimer_id": "4e8g3d11-2b3c-4d5e-6f7a-8901bcdef123"
            }]
       }'

Example: Removing a Disclaimer from an Existing Creative​

To remove the association, send the full Creative payload with the offer_disclaimer_id set to null.

curl -X PUT \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer meowmeowmeow" \
  'https://adsapi.snapchat.com/v1/adaccounts/82225ba6-7559-4000-9663-bace8adff5f2/creatives' \
  -d '{
        "creatives": [{
            "id": "7d4ce4d3-db51-4b9c-8841-0992fc589484",
            "name": "Creative With Removed Disclaimer",
            "ad_account_id": "82225ba6-7559-4000-9663-bace8adff5f2",
            "type": "SNAP_AD",
            "top_snap_media_id": "7a317143-b919-4cb0-a2c4-37e80cae0c1b",
            "offer_disclaimer_id": null
        }]
      }'
