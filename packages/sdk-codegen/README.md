# SDK codegen targets

Platform generators normalize provider specifications into one canonical `SdkIr`
and emit independent targets from that contract:

- `types` — wire-oriented TypeScript model types
- `effect` — Effect schemas, endpoint descriptors, and capability metadata
- `valibot` — lightweight runtime validation schemas

The target seam is intentionally provider-neutral. A generator supplies an IR
and chooses where its target directories are written; generated Valibot output
is opt-in at package consumption time and does not add Effect to TypeScript-only
consumers.

Webhook payloads are not generated by this pipeline. Provider webhook schemas
remain hand-authored in their owning platform package.
