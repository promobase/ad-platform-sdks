# Mosaic brand notes

Mosaic is the open-source name for this SDK family. The identity should feel like developer
infrastructure: quiet, precise, modular, and useful before it feels promotional.

## Mark

Use the open-tile `M` mark from [`apps/docs/public/mosaic-mark.svg`](../apps/docs/public/mosaic-mark.svg).
It represents one shared core with provider-specific paths opening into it.

- Prefer the monochrome mark on light surfaces.
- Use [`mosaic-mark-inverse.svg`](../apps/docs/public/mosaic-mark-inverse.svg) on dark surfaces.
- Preserve the rounded corners and the transparent `M` cutout.
- Do not add gradients, shadows, partner logos, or platform-specific colors to the mark.
- Keep enough clear space around the mark for the outer tile to remain legible at small sizes.

## Wordmark

Set `Mosaic` in the existing Inter variable font used by the documentation site. Use a semibold
weight with tight tracking. Use JetBrains Mono for package names, commands, and technical labels.

## Palette

The default identity is intentionally restrained:

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#111111` | Primary mark and headings |
| Paper | `#FAFAF9` | Light surfaces |
| Inverse | `#FFFFFF` | Dark-surface mark |
| Muted | `#737373` | Secondary copy and metadata |

Provider colors may appear in platform reference material or hover states, but they are not Mosaic
brand colors.

## Voice

Prefer direct, technical language: “generated from canonical contracts,” “one shared runtime,” and
“provider-native clients.” Avoid inflated claims, vague AI language, and marketing-first copy in
the project README.
