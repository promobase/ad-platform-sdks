Mosaic gives you provider-native clients, generated low-level contracts, and a cross-platform
operation catalog from the same packages. Start with the umbrella package unless you only ship one
integration.

## Install

```bash
bun add @openpromo/ad-platforms
```

Platform-first entrypoints such as `@openpromo/ad-platforms/facebook`,
`@openpromo/ad-platforms/instagram`, and `@openpromo/ad-platforms/tiktok`, plus individual
provider packages such as `@openpromo/tiktok` and `@openpromo/youtube`, are available when bundle
isolation matters.

## Create clients

```ts
import { Instagram } from "@openpromo/ad-platforms/instagram";
import { TikTok } from "@openpromo/ad-platforms";
import { YouTube } from "@openpromo/ad-platforms/youtube";

const instagram = Instagram.createLoginClient({
  accessToken: process.env.INSTAGRAM_TOKEN!,
  igAccountId: "ig_123",
});

const tiktok = TikTok.createClient({
  accessToken: process.env.TIKTOK_TOKEN!,
  businessId: "business_123",
});

const youtube = YouTube.createClient({
  accessToken: process.env.YOUTUBE_TOKEN!,
});
```

Pass credentials from your application at runtime. Do not bake access or refresh tokens into a
bundle, repository, or generated configuration.

## Choose the right layer

| Need | Use |
| --- | --- |
| Provider-specific breadth | A platform client or generated Effect entrypoint |
| Portable post metrics and agent actions | `@openpromo/ad-platforms/operations` |
| AI SDK tools | `@openpromo/ad-platforms/operations/ai` |
| Code Mode connector definitions | `@openpromo/ad-platforms/operations/codemode` |
| Terminal or MCP access | `@openpromo/ad-platforms-cli` |

Continue with [authentication](/guides/authentication), then choose the [Promise and Effect
runtime](/guides/promise-and-effect) or [operation catalog](/guides/agent-surfaces).
