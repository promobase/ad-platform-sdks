Basic details about a video, including title, description, uploader, thumbnails and category.

| Field | Wire name | Type | Required | Nullable | Description |
| --- | --- | --- | --- | --- | --- |
| `categoryId` | `categoryId` | `string` | No | No | The YouTube video category associated with the video. |
| `channelId` | `channelId` | `string` | No | No | The ID that YouTube uses to uniquely identify the channel that the video was uploaded to. |
| `channelTitle` | `channelTitle` | `string` | No | No | Channel title for the channel that the video belongs to. |
| `defaultAudioLanguage` | `defaultAudioLanguage` | `string` | No | No | The default_audio_language property specifies the language spoken in the video's default audio track. |
| `defaultLanguage` | `defaultLanguage` | `string` | No | No | The language of the videos's default snippet. |
| `description` | `description` | `string` | No | No | The video's description. @mutable youtube.videos.insert youtube.videos.update |
| `liveBroadcastContent` | `liveBroadcastContent` | `"none" \| "upcoming" \| "live" \| "completed"` | No | No | Indicates if the video is an upcoming/active live broadcast. Or it's "none" if the video is not an upcoming/active live broadcast. |
| `localized` | `localized` | `VideoLocalization` | No | No | Localized snippet selected with the hl parameter. If no such localization exists, this field is populated with the default snippet. (Read-only) |
| `publishedAt` | `publishedAt` | `string<date-time>` | No | No | The date and time when the video was uploaded. |
| `tags` | `tags` | `Array<string>` | No | No | A list of keyword tags associated with the video. Tags may contain spaces. |
| `thumbnails` | `thumbnails` | `ThumbnailDetails` | No | No | A map of thumbnail images associated with the video. For each object in the map, the key is the name of the thumbnail image, and the value is an object that contains other information about the thumbnail. |
| `title` | `title` | `string` | No | No | The video's title. @mutable youtube.videos.insert youtube.videos.update |

## VideoStat

`object` model on the `json` wire format.

A *VideoStat* resource represents a YouTube video's stats.

| Field | Wire name | Type | Required | Nullable | Description |
| --- | --- | --- | --- | --- | --- |
| `contentDetails` | `contentDetails` | `VideoStatsContentDetails` | No | No | Output only. The VideoStatsContentDetails object contains information about the video content, including the length of the video. |
| `etag` | `etag` | `string` | No | No | Output only. Etag of this resource. |
| `id` | `id` | `string` | No | No | Output only. The ID that YouTube uses to uniquely identify the video. |
| `kind` | `kind` | `string` | No | No | Output only. Identifies what kind of resource this is. Value: the fixed string "youtube#videoStats". |
| `snippet` | `snippet` | `VideoStatsSnippet` | No | No | Output only. The VideoStatsSnippet object contains basic details about the video, such publish time. |
| `statistics` | `statistics` | `VideoStatsStatistics` | No | No | Output only. The VideoStatsStatistics object contains statistics about the video. |

## VideoStatistics

`object` model on the `json` wire format.

Statistics about the video, such as the number of times the video was viewed or liked.

| Field | Wire name | Type | Required | Nullable | Description |
| --- | --- | --- | --- | --- | --- |
| `commentCount` | `commentCount` | `string` | No | No | The number of comments for the video. |
| `dislikeCount` | `dislikeCount` | `string` | No | No | The number of users who have indicated that they disliked the video by giving it a negative rating. |
| `favoriteCount` | `favoriteCount` | `string` | No | No | The number of users who currently have the video marked as a favorite video. |
| `likeCount` | `likeCount` | `string` | No | No | The number of users who have indicated that they liked the video by giving it a positive rating. |
| `viewCount` | `viewCount` | `string` | No | No | The number of times the video has been viewed. |
