Every generated platform package emits three views of the same canonical provider IR:

- `types` for compile-time TypeScript models and endpoint contracts;
- `valibot` for lightweight runtime validation at untrusted boundaries;
- `effect` for typed Effect schemas, endpoint descriptors, and the Effect client.

The generated surfaces are provider-specific and opt-in. They do not replace the hand-authored
publishing, OAuth, webhook, or messaging clients.

## Valibot and TypeScript

```ts
import { parse } from "valibot";
import { CampaignFieldsSchema } from "@openpromo/meta/valibot";
import type { CampaignFields } from "@openpromo/meta/types";

const campaign: CampaignFields = parse(CampaignFieldsSchema, input);
```

Use the generated Valibot schema when decoding provider-shaped JSON, fixtures, queue messages, or
other data that is not already trusted by the type system. TypeScript types alone do not validate
runtime input.

## Effect contracts

```ts
import {
  createEffectClient,
  youtube_videos_list,
} from "@openpromo/youtube/effect";

const client = createEffectClient({
  headers: { authorization: `Bearer ${accessToken}` },
});

const result = await client.promise(youtube_videos_list, {
  part: "statistics",
  id: "video-id",
});

await client.dispose();
```

Effect is useful when a service needs typed errors, interruption, composition, or managed
resources. Promise callers can use the same generated descriptors without adopting Effect across
their entire application.

## Platform subpaths

Generated packages expose the same three target names, with version or API-surface prefixes where
the provider has multiple generated contracts:

| Package | Generated surfaces |
| --- | --- |
| `@openpromo/meta` | `/types`, `/valibot`, `/facebook/effect`, `/instagram/effect`, `/threads/effect` |
| `@openpromo/tiktok` | `/types`, `/valibot`, `/effect` |
| `@openpromo/google-ads` | `/v25/types`, `/v25/valibot`, `/v25/effect` |
| `@openpromo/google-business-profile` | `/types`, `/valibot`, `/effect` |
| `@openpromo/linkedin` | `/types`, `/valibot`, `/effect` |
| `@openpromo/x` | `/types`, `/valibot`, `/effect` |
| `@openpromo/youtube` | `/types`, `/valibot`, `/effect` |
| `@openpromo/bluesky` | `/types`, `/valibot`, `/effect` |
| `@openpromo/pinterest` | `/types`, `/valibot`, `/effect` |
| `@openpromo/reddit` | `/types`, `/valibot`, `/effect` |
| `@openpromo/snapchat` | `/types`, `/valibot`, `/effect` |
| `@openpromo/amazon-ads` | Per-surface `/types`, `/valibot`, `/effect` subpaths |

For example, Amazon Ads uses `/sponsored-products/types` and `/api/valibot`, while Meta's Effect
contracts are available through `/facebook/effect`, `/instagram/effect`, and `/threads/effect`.
The [API reference](/reference) shows the source version and coverage for each platform.
