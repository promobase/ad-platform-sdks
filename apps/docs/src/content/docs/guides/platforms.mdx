| Platform | Package | High-level focus |
| --- | --- | --- |
| Facebook | `@openpromo/meta` | Graph API, Page publishing, messaging, OAuth, webhooks |
| Instagram | `@openpromo/meta` | Publishing, messaging, OAuth, webhooks, Graph API |
| Threads | `@openpromo/meta` | Publishing, replies, OAuth, Graph API |
| WhatsApp | `@openpromo/meta` | Cloud API messaging and webhooks |
| TikTok | `@openpromo/tiktok` | Publishing, comments, insights, webhooks, generated Business API |
| Google Ads | `@openpromo/google-ads` | Customer-bound resources, typed GAQL, generated v25 services |
| Google Business Profile | `@openpromo/google-business-profile` | Locations, local posts, post insights, location performance |
| LinkedIn | `@openpromo/linkedin` | Organizations, organic posts, comments, assets, OAuth |
| X | `@openpromo/x` | Posts, users, direct messages, media upload, metrics |
| YouTube | `@openpromo/youtube` | Data API resources, resumable uploads, comments, statistics |

The umbrella `@openpromo/ad-platforms` package re-exports common entrypoints while each provider
package remains independently installable. Use the provider-native client for side effects and the
generated contract subpaths for exact operations, parameters, models, scopes, and source versions.
