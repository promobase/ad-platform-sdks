| Platform | Package | High-level focus |
| --- | --- | --- |
| Meta, Facebook, Instagram, Threads | `@mosaic/meta` | Publishing, inbox, OAuth, webhooks, metrics, Graph API objects |
| TikTok Business and Developer | `@mosaic/tiktok` | Publishing, comments, insights, webhooks, generated Business API |
| Google Ads | `@mosaic/google-ads` | Customer-bound resources, typed GAQL, generated v25 services |
| Google Business Profile | `@mosaic/google-business-profile` | Locations, local posts, post insights, location performance |
| LinkedIn | `@mosaic/linkedin` | Organizations, organic posts, comments, assets, OAuth |
| X | `@mosaic/x` | Posts, users, direct messages, media upload, metrics |
| YouTube | `@mosaic/youtube` | Data API resources, resumable uploads, comments, statistics |

The umbrella `@mosaic/ad-platforms` package re-exports the common entrypoints and keeps separate
subpaths for large generated clients. Follow the [API reference](/reference) for exact operations,
parameters, models, scopes, and source versions.
