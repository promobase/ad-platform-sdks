Effect is the canonical generated runtime. Promise methods execute the same descriptor, request
mapping, decoder, and error model, so an application can adopt Effect incrementally.

```ts
import {
  createEffectClient,
  youtube_videos_list,
} from "@openpromo/youtube/effect";

const youtube = createEffectClient({
  baseUrl: "https://www.googleapis.com/",
  headers: { authorization: `Bearer ${accessToken}` },
});

const program = youtube.effect(youtube_videos_list, {
  part: "statistics",
  id: "video-id",
});

const result = await youtube.promise(youtube_videos_list, {
  part: "statistics",
  id: "video-id",
});

await youtube.dispose();
```

Use Effect inside services that benefit from typed errors, interruption, composition, and managed
resources. Use the Promise boundary at framework handlers or during incremental migration. An
aborted Promise interrupts the underlying Effect fiber and fetch request.

Imports stay platform-specific, for example `@openpromo/ad-platforms/meta/effect` and
`@openpromo/ad-platforms/google-ads/v25/effect`. The shared `@openpromo/ad-platforms/effect`
entrypoint does not eagerly load all provider schemas.
